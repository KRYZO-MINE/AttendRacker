==================================================

- CSS3
- Tailwind CSS
- Vanilla JavaScript

9. IMPORTANT ATTENDANCE LOGIC
==================================================

Implement these rules:

If Status = Present:
- In Time should normally be required.
- Out Time can remain empty if the employee has not checked out yet.

If Status = Half Day:
- In Time required.
- Out Time optional.

If Status = Leave:
- Time fields may be empty.
- The system should allow Leave without In/Out time.

If the user enters both In Time and Out Time:

Automatically calculate:

Total Hours

Example:

09:12 AM
to
06:00 PM

Result:

8h 48m

Do NOT calculate negative or invalid durations.

If Out Time is earlier than In Time:
Show:

"Out time cannot be earlier than in time."

Do not submit until corrected.

10. GOOGLE SHEET DATABASE
==================================================

The Google Sheet structure is:

In Time

Status

2026-09-22 | Anju | AB | | | Leave |
2026-09-22 | Garvi | 09:46 AM | | | Present |

The website must communicate with Google Sheets through a Google Apps Script REST API.

Create a clearly marked configuration section in JavaScript:

const API_URL = "YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL";

Do not hard-code fake API responses in the final production implementation.

Create separate functions:

fetchAttendance()
submitAttendance()
updateAttendance()
deleteAttendance()

If update/delete endpoints are not available yet, structure the code so they can easily be added later.
